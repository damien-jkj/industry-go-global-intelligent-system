# 泰国纯电乘用车出海初筛样例

本样例用公开材料展示[报告规格 v0.1](report-spec.md)的输出。场景历史截点为 2026-11-22。资料为研究样本，到实际业务时需按申报日期与车辆条件复核。

| 查询项 | 本次范围 |
| --- | --- |
| 出口地与目的国 | 中国 → 泰国 |
| 商品与业务方式 | 纯电乘用车，按整车出口场景初筛 |
| 输入编码 | HS 870380（六位统计口径） |
| 待补条件 | 车型详细规格、泰国国家税目、原产资格与证明材料 |

## 摘要

- **市场值得进一步核查。** 泰国 2025 年电动汽车销量约 14 万辆。它反映终端市场表现，不能据此判断某款进口纯电车的销量或利润。见 [M1](#m1)。
- **仍需确认国家税目。** 当前六位编码支持市场数据查询，但详情样本指向的国家税目描述与整车场景不一致。适用税率待核验。见 [A1](#a1)。

## 关税与准入初筛

| 编号 | 事项 | 当前状态 | 依据与限制 |
| --- | --- | --- | --- |
| <a id="a1"></a>A1 | 泰国具体税目与税率 | **待核验** | 六位输入为 870380。GTH 详情曾展示 87038011，描述包含未组装卡丁车。当前业务输入为纯电乘用整车，暂不采用该页税率。需用车型规格核验国家税目。[S3](#s3) |
| A2 | 优惠资格 | **待核验** | 已知出口地为中国。尚缺确认后的税目、原产条件和证明文件。先核对适用协定条款，再判断资格。[S3](#s3) |
| A3 | 适用认证及文件 | **未取得资料** | 本样例尚未完成车型级主管机关原文核验。需核实适用标准、车型条件与手续。 |

## 下一步行动

1. 补齐车辆类型、用途与详细规格，核对国家税目。[泰国海关税则入口](https://www.customs.go.th/list_strc_link_image_with_infographic.php?ini_content=customs_tariff_service&lang=en)
2. 如需更新进口规模，按相同商品编码、贸易方向和期间复核泰国海关的统计表。[泰国海关统计入口](https://www.customs.go.th/statistic_report.php?lang=en&left_menu=menu_information_service_170307_01)
3. 确认货物原产资格和可提交的证明，再核查优惠规则。
4. 向泰国相关主管机构核实该车型的标准及准入文件。把具体条款、版本和核验日期补回报告。
