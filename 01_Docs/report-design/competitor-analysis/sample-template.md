# 样本记录模板

复制本文件到 `samples/`，用平台或报告名称命名，填写实际观察到的信息。

## 样本与观察范围

记录产品或报告名、发布方、目标用户、链接、访问日期。说明查阅到的是实际查询结果、可下载报告、公开样页、操作说明还是产品介绍。如能操作，记录国家、原产地、商品、HS 编码和其他会影响结果的条件。

## 实际输出

| 观察项 | 所见内容 | 证据位置 |
| --- | --- | --- |
| 输入与摘要 | 记录必填条件、第一页或首屏优先展示的信息 | 页面链接、章节或页码 |
| 市场数据 | 记录指标、单位、统计期间、对比口径和图表形式 | 页面链接、章节或页码 |
| 关税与准入 | 记录税率类型、适用条件、法规原文及核查指引 | 页面链接、章节或页码 |
| 来源与时效 | 记录能否定位到原文，以及发布时间、生效时间和查询时间如何展示 | 页面链接、章节或页码 |
| 缺失与异常 | 记录缺少输入、无数据或资料冲突时的表现 | 页面链接、章节或页码 |
| 导出与使用 | 记录可获得的文件格式、导出内容及访问限制 | 页面链接、章节或页码 |

某项无法访问或验证时，写明原因。只有在实际检查看到明确依据时，才判断一项能力是否提供。

| 观察到的做法 | 对当前用户的价值 | 建议采用方式或暂缓理由 | 所需字段或验证办法 |
