# Global Trade Helpdesk 实测分析

Global Trade Helpdesk（GTH）最值得借鉴的是**同一组查询条件贯穿市场概览、关税、法规和原始资料入口**。这次测试也暴露了一个容易误读的地方：市场统计按六位 HS 编码展示，关税详情却落到更细的国家税目。我们的报告应在税率旁明确展示实际匹配的税目和适用条件。

## 样本与复现方式

| 项目 | 实测设置 |
| --- | --- |
| 平台 | Global Trade Helpdesk，由 ITC、UNCTAD 和 WTO 共同推动，面向企业特别是中小微企业提供贸易信息查询 |
| 场景 | 中国出口至泰国，纯电乘用车产品组，用于对照市场扫描和准入筛查 |
| 商品口径 | 六位 HS `870380`，联合国统计司 HS 2017 将其列于乘用机动车品目下，适用于仅以电机驱动的车辆 |
| 核验日期 | 2026-11-21，未登录 |
| 实际查看 | 市场概览、关税详情、法规分类及泰国产品要求详情 |

从[实测结果页](https://globaltradehelpdesk.org/en/export-870380-from-cn-to-th/market-overview)进入。也可在[平台首页](https://globaltradehelpdesk.org/en)选 Exporting，填写 China、870380、Thailand 后查看结果。六位编码用于本次对照研究，具体车辆仍需确认进口国税目。参见[联合国统计司编码说明](https://unstats.un.org/unsd/classifications/Econ/Structure/Detail/EN/2089/870380)和 [UNCTAD 平台说明](https://unctad.org/es/node/2844)。

## 实际输出与版式

| 观察项 | 实际看到的内容 | 对报告设计的启发 |
| --- | --- | --- |
| 首屏和导航 | 顶部重述方向、出口国、产品编码与目标市场，可点 Edit。概览把市场吸引力、关税、强制要求等分成区块，一侧有章节锚点。结果页另有 Market access、Sustainability、Go digital、Partners 等入口。[市场概览](https://globaltradehelpdesk.org/en/export-870380-from-cn-to-th/market-overview) | 报告顶部常驻查询范围，下方先给摘要，再按主题展开；合作伙伴等通用信息可按场景显示。 |
| 市场指标 | 市场概览把泰国的全球进口与来自中国的进口表现分开。页面显示 2025 年该产品全球进口额约 21.5 亿美元，其中中国占 92%，并给出 2017–2025 年贸易额折线和 Trade Map 入口。另有出口潜力估计及替代市场，后者明确使用较宽的 `8703XX` 口径。[市场概览](https://globaltradehelpdesk.org/en/export-870380-from-cn-to-th/market-overview) | 指标卡同时展示数值、单位、统计期和范围。进口额可提供市场信号，估计与实绩分开标记，避免将更宽品类的估计直接套给当前产品。 |
| 关税与原产地 | 概览显示 0–80% 的区间。详情页显示具体税目 `87038011`，商品描述包含未组装卡丁车，并列出最惠国税率和对中国优惠税率。页面还列出协定、原产地条件说明和协议文件入口。外链参数指向 2021 年查询。[关税详情](https://globaltradehelpdesk.org/en/export-870380-from-cn-to-th/assess-requirements/tariffs) | 不能把详情页的数字当作所有纯电乘用车的当前税率。报告要展示查询编码与实际匹配税目、数据年份、协定及适用条件。归类或原产资格不清楚时标为待核验。 |
| 准入与来源 | 法规按出口地要求、进口国产品要求、市场条件、装运前与检验、监管变更通报分组。泰国产品要求页显示 1 条产品质量、安全或性能要求，标注 UNCTAD（2021），并提供 Market Access Map 深查入口。[法规分类](https://globaltradehelpdesk.org/en/export-870380-from-cn-to-th/assess-requirements/regulations) · [泰国产品要求](https://globaltradehelpdesk.org/en/export-870380-from-cn-to-th/assess-requirements/regulations/product-requirements) | 分类条目可作为核查入口。对具体产品作出适用性判断时，再补主管机构、政策原文位置、生效状态和适用条件。 |
| 缺失与访问限制 | 概览的电商免税门槛卡片只显示未填完整的提示，并提供详情入口。企业目录注明 Trade Map 企业资料面向登录后的订阅用户或合作方。[市场概览](https://globaltradehelpdesk.org/en/export-870380-from-cn-to-th/market-overview) | 缺失值直接说明缺的是什么，附复核入口。需要登录和资料未核验应分别标注。 |
| 报告与导出 | 本次查阅的三个主题下可见结构化网页、分项跳转与部分协定文件链接。未在已查页面看到整份场景报告的下载入口，未核验登录后的导出功能。 | 对照的是查询结果的组织方式。产品报告若要便于分享，应保证摘要、查询范围和来源随报告一起保留。 |

表内数值用于说明平台呈现方式。本次未对统计底表和泰国当前适用税率做独立核验。

## 转成我们的报告要求

| 建议优先级 | 做法 | 需要的字段 | 如何检查 |
| --- | --- | --- | --- |
| 高 | 首屏展示查询范围和待确认条件 | 目标市场、出口地、原产地及确认状态、产品、业务方式、输入 HS 编码、查询日期 | 从摘要跳到关税或合规章节，仍能辨认同一业务场景。 |
| 高 | 数值旁标明统计期间和口径 | 指标名、数值、单位、期间、商品范围、观测或估计类型、来源 | 样例同时含历史值和估计值时，读者能区分二者。缺少单位或期间时提示待核验。 |
| 高 | 将国家税目、关键适用条件和证据绑定在每条结果上 | 实际匹配税目与版本、税率类型、适用条件、政策生效时间、来源链接及条款位置、核验状态 | 六位编码对应多个国家税目，或查询商品与匹配描述不符时，不输出确定的适用税率，并指出需补齐的信息。 |
| 中 | 以待办清单收束报告 | 待核验事项、影响、下一步动作、对应证据 | 读者能从每项建议回到造成该建议的证据或信息缺口。 |

GTH 的优势是同屏整合多类贸易信息，并连接专业工具继续查询。我们的拟议价值是在一个具体业务场景里，把已核验的数据、暂无法确认的事项和下一步动作整理成可分享的中文报告。后续可用同一组输入验证这套报告是否减少用户查找相关证据的步骤。
