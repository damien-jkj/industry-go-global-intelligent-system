# Market Access Map 样本分析

ITC 的 Market Access Map（MAcMap）适合做准入证据查询。对我们的报告，最值得借鉴的是**按商品归类和数据年份逐项展示关税，并把优惠资格和监管要求作为有条件的核查事项**。

## 样本与观察范围

沿用 [Global Trade Helpdesk 的参照场景](global-trade-helpdesk.md)，出口方为中国，进口市场为泰国，商品为纯电乘用车产品组（六位 HS `870380`）。这是调研口径。具体车型、进口国税目和优惠原产资格需要另行确认。

2026-11-22 查阅了 ITC 的公开首页、方法说明和 FAQ，并从 GTH 关税页进入同一场景的历史查询。浏览器停留在站点安全验证页，未到达结果表或登录页。本记录用官方公开资料核对平台的界面入口和数据定义，具体税率、部分结果的展示细节及导出权限仍待实测。[平台首页](https://www.macmap.org/?trk=organization-update_share-update_update-text) · [GTH 关税页](https://globaltradehelpdesk.org/en/export-870380-from-cn-to-th/assess-requirements/tariffs) · [历史查询链接](https://www.macmap.org/en/query/customs-duties?reporter=764&year=2021&partner=156&product=870380&level=6)

## 平台输出与报告设计启发

| 观察项 | 公开页面或方法说明中的做法 | 对我们报告的启发 |
| --- | --- | --- |
| 输入与导航 | 首页显示出口方、目标市场及商品选择框，支持 HS6 或国家税目。平台将准入查询、横向比较、协定等专题分析及数据下载放入不同入口。[平台首页](https://www.macmap.org/?trk=organization-update_share-update_update-text) | 报告首屏复述查询条件，区分出口地与原产地，标明输入编码和实际匹配的细分编码。 |
| 对比范围 | 税率比较可按目的地、出口伙伴或商品展开，方法说明另列历史关税查询。首页提供交互图表及地图的功能说明。本轮未核验该商品的比较图表或贸易指标。[关税方法](https://www.macmap.org/en/about/methodology) · [平台首页](https://m.macmap.org/en) | 同一个表里固定其余条件，只改变一个比较维度。注明指标口径、适用年份和单位，避免混用不同税目。 |
| 国家税目与税率类型 | 关税方法指出，进口国执行的税则细分到国家税目。平台所定义的 HS6 汇总，可由其覆盖的各国家税目最低可用税率求简单平均。详细查询可区分一般税率、最惠国适用税率和优惠税率。[关税方法](https://www.macmap.org/en/about/methodology) | HS6 汇总有比较价值，单笔业务仍需按国家税目核实。把优惠税率和资格条件放在同一行，原产资格未知时提供核查入口。 |
| 监管要求 | 官方方法列出非关税措施分类、法规标题与摘要、主管机构、有效性、适用国家及商品等字段。也可查询关税配额和贸易救济。[非关税措施方法](https://www.macmap.org/about/methodology/ntm) · [ITC 工具介绍](https://southeastasiaknowledge.intracen.org/local/itcacademy/page.php?id=90) | 合规表以措施为单位保留适用范围、主管机构和证据定位。配额和救济措施可在找到对应证据后按场景展示。 |
| 来源、时效与缺失 | 官方 FAQ 说明税率数据来自国家联络渠道，按国家尽可能每年更新，年内调整未必及时覆盖。FAQ 区分零税率与无可用数据，并说明很小的正值可能显示为 `0.00%`。[官方 FAQ](https://www.macmap.org/en/resources/faq) | 每条结果分别记录数据年、政策生效时间和访问日期。把明确零税率、显示精度导致的近零、未收录或待核验作为不同状态。 |
| 导出与报告 | 首页介绍可打印结果、下载图表与 Excel。FAQ 另说明支持多年定制数据下载，当年数据可能受限。本次未生成导出文件，整份场景报告和登录后的权限均待核验。[平台首页](https://m.macmap.org/en) · [官方 FAQ](https://www.macmap.org/en/resources/faq) | 输出的表格和来源说明应随报告一起保留。数据下载能力和成品报告能力分别评价。 |

**该场景最值得复查的点。** GTH 在详细页显示了 `87038011`，描述涉及未组装卡丁车，跳转 MAcMap 的链接却使用六位 `870380`、`level=6` 和 `year=2021`。仅凭这条链接无法确认目标站最终显示的税目和税率。我们的报告遇到这种证据粒度差异时，应标明「需确认泰国国家税目」，保留查询入口，待产品规格与税目对应后再给适用税率。[GTH 关税页](https://globaltradehelpdesk.org/en/export-870380-from-cn-to-th/assess-requirements/tariffs) · [跳转目标](https://www.macmap.org/en/query/customs-duties?reporter=764&year=2021&partner=156&product=870380&level=6)

## 转成我们的报告要求

| 优先级 | 报告做法 | 建议字段 | 验收用例 |
| --- | --- | --- | --- |
| 高 | 显示商品归类层级和状态 | 输入 HS、HS 版本、国家税目、税目描述、匹配状态、待补产品信息 | 仅输入 `870380` 且候选涉及不同车型时，展示候选与待确认点，不给单笔适用税率。 |
| 高 | 把优惠税率和条件放在一起 | 税率类型、协定名称、适用条件、原产资格状态、所需证明、数据年、生效期 | 测试优惠税率存在但原产地证明未核实时，报告明确提示资格待核验。 |
| 高 | 保留每条准入措施的证据 | 主管机构、措施类别、适用商品与市场、法规名称、链接、条款、有效性、核验日期 | 核查清单可回到具体证据。数据只到 2021 年时，显示来源年份并列出当前版本复查动作。 |
| 高 | 区分已确认的零与信息缺口 | 原始值、单位、展示精度、数据状态、状态原因、下一步核实动作 | 来源明确的零税率、显示为近零及缺少数据分别呈现。 |
| 中 | 用表格辅助市场比较 | 比较对象、共同商品口径、年份、税率类型、来源 | 两个市场的国家税目不可直接对齐时，明确共同比较层级和限制。 |

编写报告时，可先用 MAcMap 的字段框架规范准入表，再从进口国主管部门材料核对时效与适用条件。若后续能够打开结果页，优先复查同一六位编码展开后的国家税目、可选年份、贸易伙伴条件及单页导出的内容。
