# Amazon Product Opportunity Explorer

## 样本与观察范围

2026-11-22 核对 Amazon 官方产品页与公开教程。教程展示了「dog beds」需求组的高点击商品，用于观察站内选品分析。Seller Central 的实际结果、站点覆盖和导出格式未登录核验。[产品说明](https://sell.amazon.com/tools/product-opportunity-explorer/) · [公开样本教程](https://sell.amazon.com/blog/product-opportunity-explorer)

## 可核验的输出

| 观察项 | 官方说明及样例 | 对报告设计的启发 |
| --- | --- | --- |
| 查询对象 | 可按关键词、商品或类别找到需求组。Amazon 根据搜索后浏览和购买的商品归并搜索词，同一词或商品可能出现在多个需求组。公开教程以狗床为示例。 | 保留需求组及其定义。同一个 HS 编码或商品类别未必对应唯一的电商需求组。 |
| 指标组合 | 官方说明覆盖搜索、价格、竞争、评论、退货等。教程举例把搜索增长与缺货率一起读，再看具体商品。 | 将关注度、成交、供给与售后信号分别写清，避免用搜索量直接推算潜在销量。 |
| 更新与访问 | 教程说明需求组指标每周刷新、新需求组按月创建。该口径来自公开教程，当前各站点的刷新与权限有待实测。官方入口要求进入 Seller Central。 | 同时保存统计期、数据来源和获取时间。登录或权限限制写在来源卡。 |
| 输出形式 | 本轮核对的是功能介绍和公开样例图。截图展示站内需求组及商品层级，未核验账号内的整份报告导出。 | 网页可用分组摘要加明细，分享版本保留口径和来源。 |

## 转成我们的报告要求

| 设计 | 字段 | 验收 |
| --- | --- | --- |
| 给站内指标标记来源范围 | 平台、站点、商品或需求组、指标定义、统计期 | 有 Amazon 指标时，读者知道它来自哪个站点和分组。没有证据覆盖泰国或印尼时，不给当地的量化结论。 |
| 将热度与成交信号分列 | 搜索量、成交量、供给或缺货指标、来源链接 | 只有搜索信号时，报告说明还需要交易数据。多个有重叠的需求组不合计。 |

该样本用于跨境电商章节的字段设计。整车场景仍采用商品贸易统计和准入依据。
