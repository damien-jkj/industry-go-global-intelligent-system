# 美国商务部 Market Diversification Tool 样本分析

这个样本适合参考**市场概览如何连接分项依据，以及交互分析如何变成可带走的报告**。美国商务部国际贸易管理局（ITA）的工具面向美国出口企业，用候选市场、商品和业务条件生成对比结果。借鉴其信息组织和导出方式，可为中泰场景保留可追溯的结论和核查路径。[工具介绍](https://www.trade.gov/market-diversification-tool)

## 样本与观察范围

| 项目 | 本次核验 |
| --- | --- |
| 角色与场景 | 市场拓展人员筛选新市场。采用 ITA 公开的美国空压机（HS 841480）示例，当前市场为墨西哥，比较其他拉美候选市场。 |
| 核验日期与材料 | 2026-11-22。核对官方操作指南、结果解读、公开导出页示意、指标说明及 FAQ。 |
| 证据边界 | 下文分值来自官方教程的演示条件。本轮没有自行运行仪表板或下载新报告，导出格式和组成来自官方操作说明。 |

[官方结果示例](https://www.trade.gov/market-diversification-tool-understanding-results) · [公开导出页示意](https://www.trade.gov/sites/default/files/2024-09/Report%20Export.png)

## 输出与报告结构

| 观察项 | 官方示例或说明 | 对出海报告的启发 |
| --- | --- | --- |
| 输入和比较范围 | 先选择新出口商或现有出口商，再填商品、当前市场（如适用）与目标市场，指标权重可以调整。市场得分按本次候选对象相对计算，改变比较对象或权重就可能改变排序。[操作指南](https://www.trade.gov/market-diversification-tool-tutorial) · [FAQ](https://www.trade.gov/market-diversification-tool-faqs) | 摘要和导出件保留目标市场、商品、HS 层级、比较对象及口径。若以后加入综合评分，需同时显示公式、默认权重、数据覆盖和分项贡献。 |
| 概览与明细 | 官方空压机示例中巴西为 87.32 分，阿根廷为 58.89 分。分项表显示两者从美国进口规模接近，结果解读随后用巴西较大的进口份额差距和较快的进口增长解释为什么值得进一步查看。结果页还有单一市场详情和至多五个市场的对比视图。[结果解读与图示](https://www.trade.gov/market-diversification-tool-understanding-results) | 先说明哪些市场信号值得追，再让读者回到明细和统计期。解释要区分观察到的指标、推断及待核验因素。 |
| 来源及缺失处理 | 商品层面包含进口、贸易潜力和关税指标，国家层面另有物流、监管质量等指标。贸易采用进口市场上报数据，是否具备数据及是否纳入计算可通过数据可用性表检查。缺必要数据、所选商品无进口、已选为现有市场等情况都可能使结果不显示。[指标方法](https://www.trade.gov/market-diversification-tool-indicators) · [FAQ](https://www.trade.gov/market-diversification-tool-faqs) | 对每个候选市场展示数据覆盖，注明缺失、零值和排除规则，避免读者因榜单缺一行就判断该市场无需求。宏观监管指标与具体车型的准入结论分开。 |
| 分析与导出 | 官方指南列明图表数据可导出 Excel 或汇总 CSV。整份报告可导出 PDF、PowerPoint 或 PNG，包含输入与权重、结果概览及表格、指标说明、选择的单国或对比图、来源及下一步指引。[导出操作说明](https://www.trade.gov/market-diversification-tool-tutorial) | 可分享的正文同时留存场景和依据。图表的结构化数据用于复算，文件内容依据首版交付能力取舍。 |

## 转成我们的报告要求

| 优先级 | 设计及必要字段 | 验收检查 |
| --- | --- | --- |
| 高 | 摘要保留商品说明、HS 编码与层级、原产地、目标市场、统计期与生成时间。 | 同一报告脱离网页分享后，读者仍能复述查询条件，并区分数据统计期和报告日期。 |
| 高 | 市场观察关联指标值、单位、对比基期、来源以及下一步核查动作。 | 从摘要所写的增长或差异能定位到对应图表，可按相同口径复核。 |
| 高 | 缺失记录保留原因和后续核实入口。 | 比较泰国和印尼时，缺数据的市场保留一行及原因，可与已有证据支持的零值或未纳入比较相区分。 |
| 后续评估 | 若加入评分，保留候选集合、各指标权重、缺失值策略与计算版本。 | 改变候选市场或权重时，页面和导出件都能说明分值为何变化。 |

ITA 的贸易潜力、协定和基准由美国出口视角定义。本项目目前可以先用对齐口径的市场指标和产品适用条件帮助用户筛查，再根据数据验证结果决定是否要加入市场排序。
