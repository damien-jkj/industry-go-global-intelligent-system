# ITC Trade Map 样本分析

Trade Map 可作为出海报告**市场扫描章节**的参考。值得借鉴的是把贸易指标、历史变化和来源放在同一个查询口径下，让读者从一个判断追到对应序列。试做报告时，优先解决“哪国报告的数据、与谁发生的贸易、什么时间、以什么单位计”的问题。

## 样本与复现方式

| 项目 | 本次设置 |
| --- | --- |
| 平台 | 国际贸易中心（ITC）的贸易统计查询工具 |
| 场景 | 中国出口至泰国，参照 Global Trade Helpdesk 样本查询纯电乘用车产品组 |
| Trade Map 查询口径 | 货物、进口方向、报告方泰国（764）、贸易伙伴中国（156）、六位 HS 870380、直接统计、表格视图 |
| 核验日期 | 2026-11-22 |
| 核验范围 | 已核对 GTH 提供的查询入口、ITC 公开介绍、官方手册及 FAQ。浏览器打开深链后停在加载提示，未取得该查询结果表和下载件，也未出现登录提示。 |

从 [GTH 市场概览](https://globaltradehelpdesk.org/en/export-870380-from-cn-to-th/market-overview) 的 Trade Map 链接进入 [双边进口表](https://trademap.org/en/goods/trade-indicators/imports/c/764/c/156/p/870380/byProduct/6/direct/table)。泰国报告的自中国进口，与中国报告的对泰出口，可用来核对差异。HS 870380 在 HS 2017 指乘用机动车品目下仅以电机驱动的车辆，这里用作贸易统计的商品分组。[联合国统计司 HS 分类](https://unstats.un.org/unsd/classifications/Econ/Structure/Detail/EN/2089/870380)

## 可核验的内容与版式

| 观察项 | 公开证据 | 可借鉴的做法 |
| --- | --- | --- |
| 输入与结果组织 | GTH 深链明确包含方向、报告方、伙伴方、商品、统计视图与直接统计选项。官方旧版手册第 2.3 节展示如何区分按商品和按国家查看结果。[双边进口表](https://trademap.org/en/goods/trade-indicators/imports/c/764/c/156/p/870380/byProduct/6/direct/table) · [ITC 手册](https://www.trademap.org/Docs/TradeMap-Userguide-EN.pdf) | 报告将查询条件写在市场章节标题旁，也随数据图表保留。把“泰国从中国进口”与“泰国从全球进口”分别标清。 |
| 指标与时间序列 | 旧版手册第 2.3 节区分贸易指标和时间序列，指标可包括贸易额、数量、份额及增长等，时间序列支持年、季或月。ITC 新版说明提到改进表格与可视化，加入时间推移视图。本场景具体可选项待核对。[ITC 手册](https://www.trademap.org/Docs/TradeMap-Userguide-EN.pdf) · [ITC 2026 年一季度更新说明](https://marketanalysis.intracen.org/static/media/2026-Q1-Market_Analysis_Services_Update.0ddfd894.htm) | 首屏给关键指标，趋势图说明指标为什么变化或哪些变化待核实。表格保留各期原值、单位和缺失标记，便于复算。 |
| 来源与时效 | ITC FAQ 说明，二、四、六位 HS 年度数据主要来自 UN Comtrade，部分由国家来源补充，月度和季度来自国家或区域来源。旧版表格以脚注指明数据来源。数据到达时间因报告方与期间而不同。[Trade Map FAQ](https://legacy.trademap.org/stFAQ.aspx) | 每个图表分别记录统计期、来源和查询日期。若报告方一年未报，说明最近已有期间或镜像来源。 |
| 直接统计与镜像统计 | ITC 将贸易伙伴报告的数据作为直接统计缺失时的镜像资料。两者可能因进出口估价基础、归类和统计口径不同而产生差异。ITC 明确说明同一贸易流的两种记录不能相加。[Trade Map FAQ](https://legacy.trademap.org/stFAQ.aspx) | 图表有直接或镜像标签。混用了两种来源的年份须明确标注，进口额与出口额有差异时可并列解释。 |
| 下载与复用 | 旧版手册第 2.4.4 节图 52 展示表格下载栏与表格、图形、地图的视图切换。旧版 FAQ 说明部分数据根据来源政策可能限制下载。新版该查询的导出格式及登录条件待核验。[ITC 手册](https://www.trademap.org/Docs/TradeMap-Userguide-EN.pdf) · [Trade Map FAQ](https://legacy.trademap.org/stFAQ.aspx) | 报告中的图表即使被单独分享，也要保留查询范围、单位、期间和来源。 |
| 合规分析边界 | 旧版手册将从价等值税率列为部分贸易指标。此处关注展示贸易数据的方式，具体产品适用的税目、协定及认证仍需核对市场准入资料。[ITC 手册](https://www.trademap.org/Docs/TradeMap-Userguide-EN.pdf) | 市场指标与合规判定分区。贸易指标中的税率随指标定义展示，产品实际适用条件另行核验。 |

GTH 样本记录了 2025 年泰国该产品全球进口额及中国份额。这些值目前仍是 [GTH 观察值](global-trade-helpdesk.md)，未用 Trade Map 结果独立复核。

## 转成我们的报告要求

| 做法 | 建议字段 | 验收检查 |
| --- | --- | --- |
| 指标标题体现贸易流与口径 | 报告方、伙伴方、进出口方向、HS 编码及版本、金额和单位、期间 | 用户能区分泰国全球进口、泰国自中国进口和中国对泰出口。 |
| 份额和增速可复算 | 分子、分母、统计期、计算方式、引用编号 | 例如中国份额的分子和分母使用同一期间、同一商品范围的泰国进口额。全球总额缺失时显示暂无法计算。 |
| 说明统计来源和缺失 | 直接或镜像、报告方、原始来源、取得时间、缺失或替代原因 | 缺失值显示为“未取得”或“未报告”，可和零区分。镜像记录带明确标签，两种统计不会被重复累计。 |
| 图表可单独核查 | 指标名、单位、期间、来源链接或编号、必要的口径注释 | 图表标题或脚注与正文引用一致，复制图表后仍能确认统计口径。 |

## 后续实测

打开双边表后，先核对报告方、伙伴方、币种单位、期间、数据脚注与商品归类，再比较同年泰国全球进口表，检查份额能否复算。登录如为必要条件，请用户在 Trade Map 页面完成登录，再记录表格视图、缺失提示及实际可用的下载格式。
