# 出海分析报告设计

本目录记录系统为企业用户生成的出海分析报告如何设计，供中期《系统设计报告》引用。任务范围与交付进度见 [Issue #2](https://github.com/damien-jkj/industry-go-global-intelligent-system/issues/2)。

| 顺序 | 交付物 | 产出与状态 |
| --- | --- | --- |
| 1 | [竞品与报告样本分析](competitor-analysis/README.md) | 含 12 份样本及[差异与设计取舍](competitor-analysis/differentiation.md)。 |
| 2 | [报告设计规格](report-spec.md) | v0.1 待组内评审，含输入、必需字段、证据状态和验收用例。 |
| 3 | [场景示例](report-example.md) | 泰国整车出口样例，涵盖市场数值与准入待核验两类输出。 |

需求—模块对应表与开题变更说明交给成员 6 统稿。对应表沿用团队需求编号，关联功能、输入输出和检查方法。变更说明记录原方案、当前方案、原因、影响及确认状态。

报告设计负责定义输出内容、展示规则和验收标准。接口与数据库由后端任务对接，页面呈现由前端任务对接，证据检索与生成由数据与 AI 任务对接。
