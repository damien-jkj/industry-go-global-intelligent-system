# 任务四：企业需求、竞品比较与出海报告设计

供成员 6 编入中期《系统设计报告》。系统服务于开拓海外市场的中国企业。本学期聚焦泰国、印尼的新能源汽车与跨境电商场景。报告以中国企业评估纯电乘用整车进入泰国市场为例，读者可以尚无当地客户、申报编码和渠道报价。[任务四要求](https://github.com/damien-jkj/industry-go-global-intelligent-system/issues/2) · [任务一 V0.0 范围与选型](https://github.com/damien-jkj/industry-go-global-intelligent-system/blob/7d85030de308e140d89934decc572e1742becf0d/01_Docs/system-overview-and-scope.md)

## 一、需求—模块对应表

下表对应规划中的系统功能。泰国报告样例已验证内容呈现和本地交互，数据库检索、模型生成与跨模块联调仍属后续实现。

| 企业需求 | 对应功能 | 技术模块 | 判断功能可用的依据 |
| --- | --- | --- | --- |
| 了解目标国与行业 | 按国家、行业查询市场规模和增长 | FastAPI 查询 MySQL 指标表 | 切换泰国与印尼时，数值、币种、统计年份和来源随市场切换。 |
| 查看市场分布 | 地图选择市场，图表比较同口径指标 | Vue 3、ECharts、国别查询接口 | 地图选择与看板一致；销量与进口额分别展示。 |
| 估算进口关税 | 匹配目的国税目，分别计算普通和协定待遇 | FastAPI、MySQL 税则与协定记录 | 同一计税价格可复算两种税额，车型或原产条件不足时保留条件说明。 |
| 判断新能源政策和准入要求 | 检索产业激励、标准和认证的适用范围 | MySQL 条件过滤、Chroma 政策检索、RAG 归纳 | 结论能定位原文，区分整车进口与本地生产的政策窗口。 |
| 查询跨境电商政策 | 按国家、商品和寄递方式查询进口条件 | FastAPI、政策知识库与问答模块 | 同一问题遇到新旧政策时显示生效日；申报金额影响结果时说明原因。 |
| 获得出海建议 | 汇总市场、壁垒、风险与行动，生成中文报告 | FastAPI 报告接口、RAG、模型与前端报告页 | 核对关键数值和引用；缺少渠道报价时仍能给出有依据的市场初判。 |

GTH 已能把市场与准入资料串联。本组实测从六位商品编码进入详情时，落到含未组装卡丁车的细分税目。由此确定本系统的设计重点：报告把用户商品描述、候选税目、适用条件和证据放在一起。能否节省核查时间，仍需用同一道题与现有工具比较。[差异与验证方法](competitor-analysis/differentiation.md)

## 三、出海分析报告结构

报告沿用用户在市场看板选定的国家和行业，确认商品、发货地与业务方式。首页给出目标市场、统计期间和进入初判。市场章节呈现行业规模、竞争车型与价格口径。政策章节并列税率、适用税目、测算金额和政策期限。准入章节说明技术文件和办理条件。风险说明跟随相应判断，例如促销到期影响价格比较，原产资格影响优惠测算。末尾按企业所处阶段给出行动建议，并附可定位到原文的来源索引。[报告规格与验收用例](report-spec.md) · [完整案例](report-example.md)

## 四、开题方案与当前设计的差异

对照最终开题 PPT 第 4 至 6 页的核心流程、验收指标和技术架构。两国、两类场景的 MVP 定位在开题阶段已经确定。

| 开题基线 | 当前设计及原因 | 状态与后续工作 |
| --- | --- | --- |
| 按国家和行业选择资料，展示市场并筛查关税认证 | 增加商品形态、业务方式和预计进口时间。行业标签不足以确定一款车对应的税目或政策窗口。 | 已写入规格。下一步由数据与后端验证匹配字段，补齐印尼和电商样本。 |
| 报告按市场机会、壁垒、风险、行动四部分组织，关键结论可追溯 | 保留四类内容，把风险放在对应数字或措施旁，增加条件化税额对照与早期渠道建议，方便企业比较进入成本。 | 已有泰国案例。联调时同时检查开题的条数、篇幅目标和来源适用性。 |
| 检索一次后生成报告 | 企业可陆续取得报价或原产证明。设计允许一次补充多项、预览草稿、生成新版并回看变化。 | 离线交互样例可演示；持久化、重新检索及纳入本期交付仍待组内评审。 |
| 开题采用 MySQL 与检索增强生成，提出通义千问接口 | 任务一 V0.0 细分 MySQL 和 Chroma 的职责，并提出优先本地验证、保留云端接入。 | 模型部署口径由团队统筹。本分支提供输入输出和引用核验用例，待接口接入后验证。 |

全球产业扫描、上下游匹配及投资研判列入长期方向。本次交付覆盖报告设计与论证；扩大国家、行业或业务功能覆盖时，应增加相应用例并重新核对数据依据。
