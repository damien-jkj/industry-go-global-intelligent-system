# 出海分析报告规格 v0.1

适用对象为中国企业负责出口业务与市场拓展的人员。目标是完成泰国或印尼市场进入前的第一轮核查。本文为组内评审初稿，字段用于对齐界面和生成结果，接口命名由团队确认。[取舍依据](competitor-analysis/differentiation.md) · [场景样例](report-example.md)

## 输入与查询范围

| 输入 | 要求与处理 |
| --- | --- |
| 目的国、商品描述、业务方式 | 必填。区分汽车整车出口和跨境电商寄递；具体商品及目标国需在已核验资料覆盖范围内。 |
| 出口地、原产地、HS 编码 | 分开记录。原产地及 HS 可暂未确认，报告保留状态。对关税或优惠需要的字段发起补问。 |
| 预计进口日期 | 未指定时用查询当日作为分析日期，报告中明示。生成日期、政策生效日期和统计期分别记录。 |
| 场景补充条件 | 汽车先确认整车或散件、车辆用途等与归类有关的特征。电商先确认商品、销售渠道、寄递方式和申报估值口径。按实际需要追问。 |

## 页面结构和字段

| 区块 | 必需内容 | 展示规则 |
| --- | --- | --- |
| 查询范围与摘要 | 商品、路线、业务方式、分析日期、主要发现、重要缺项 | 首屏保留条件，每条重要发现引用正文条目。 |
| 市场观察 | 指标、数值或缺失状态、单位、期间、统计范围、来源 | 销量、进口额和当地生产分列。数据范围不同则不合算或直接比较。 |
| 关税与准入 | 事项、查询编码、匹配税目或候选、适用条件、有效时间、状态、依据 | 最惠国、优惠税率及资格分开。法规来源注明发布机构和条款或页码。 |
| 待核验与下一步 | 缺项或冲突、对判断的影响、补充材料、核查入口、关联条目 | 先列阻碍税目、资格或准入判断的事项。 |
| 来源与版本 | 来源编号、机构、标题、链接、定位、文件日期、有效期间、核验日期 | 来源随具体条目出现。参考链接与能支持当前结论的证据分别标注。保存每次生成所用的证据版本。 |

结论状态使用 **已核验、待核验、未取得资料、来源冲突、不适用**。已核验要求事实依据和适用条件均成立。报告可以保留已核验的部分；税目、期限或资格有关键缺项时，暂缓给出确定的税率或合规判定。缺失不得填成零。原文存在新旧版本时按适用日期及可确认的替代关系筛选；无法确认同一适用范围或版本关系时，列出差异及核查入口。

## 生成与核验

1. 后端按场景查结构化数据与已核验资料，给每条证据分配引用编号。记录查询时点及资料版本。
2. 模型分节归纳，输出结论、引用编号、限制及待补条件。税率和统计值以结构化记录为准。
3. 程序校验引用是否存在、国家和日期是否匹配、数值及单位是否一致。字段缺失时该条转入待核验。测试阶段由成员核对关键结论是否被原文支持。
4. 前端按固定版式呈现。若本期交付导出，导出件应保留输入条件、数据口径、来源和缺失状态。

## 验收用例

| 用例 | 输入与依据 | 预期结果 |
| --- | --- | --- |
| RPT-01 税目不足 | 中国到泰国，纯电乘用车，仅给 HS 870380。候选明细口径与商品描述不符。 | 正常显示已取得的市场信息。关税提示补充车辆特征与国家税目，保留外部核查入口，适用税率为空。 |
| RPT-02 政策版本 | 泰国低值网购寄递场景，同时提供旧 FAQ 和 2026 年起调整的官方说明。 | 标明两条来源的日期和适用范围。新旧关系可确认时使用分析日期适用的记录；关系或适用条件不足时列明差异并给核查动作。 |
| RPT-03 指标口径 | 同时输入 IEA 泰国电动汽车销量与 GTH HS 870380 进口数据。 | 分列统计对象、时间与单位。分析可以指出变化，不能仅凭销量增长断言具体商品更适合进口。 |
| RPT-04 引用不可用 | 生成结果引用未入库编号，或引用材料来自另一国家。 | 对应结论不显示为已核验，也不影响其他可核验区块展示。 |

待评审项包括印尼和电商的实际样本覆盖、报告生成接口字段、资料复核负责人，以及开题的条数和字数指标如何与真实证据覆盖对齐。样例用于确认设计，不构成覆盖承诺。

交互式补问与报告版本更新目前作为拟议方案，评审问题见[设计决策记录](design-decisions.md)。
