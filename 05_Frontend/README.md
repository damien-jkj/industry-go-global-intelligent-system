# 远航 · 前端交互原型

依据项目计划书与 issue #3，使用 Vue 3 + Vite + Element Plus + ECharts + Axios。

```powershell
cd D:\软工管\05_Frontend
npm install
npm run dev
```

打开终端显示的地址，默认 http://127.0.0.1:5173 。构建：`npm run build`。

四个页面：首页、市场看板、合规筛查、AI 智能问答。详见 DESIGN.md。
所有政策和问答均为明确标识的演示占位；未连接真实后端或 AI。
地图为东南亚位置示意，精确世界底图待接入。接口提案见 src/api.js。
